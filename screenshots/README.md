# Screenshots

This directory contains screenshots generated by Playwright testing scripts for the escalated notifications feature.

## Setup

### Prerequisites
Before running the scripts, make sure you have:
1. **Development server running**: Start the client development server
   ```bash
   cd client
   npm run dev  # Runs on http://localhost:5173
   ```

2. **Playwright installed**: Install Playwright with browser binaries
   ```bash
   npm install --save-dev playwright
   npx playwright install firefox  # Firefox works better in containers
   npx playwright install chromium  # Fallback option
   ```

   **Note**: If you encounter system library errors in containerized environments (like dev containers or CI), the scripts will automatically try Firefox first, then Chromium. If both fail, use the manual screenshot option below.
# Make sure dev server is running in another terminal
cd client && npm run dev

## Does Automation Work in VS Code Dev Environments?

**Short answer**: Automated browser testing (like Playwright) can work in VS Code dev environments, but often has limitations due to containerized setups missing GUI libraries.

### When Automation Works:
- ✅ **Local VS Code** with full system access
- ✅ **GitHub Codespaces** with proper system dependencies installed
- ✅ **Dev containers** with GUI libraries pre-installed
- ✅ **CI/CD pipelines** with browser testing configured

### When Automation Fails:
- ❌ **Default dev containers** (missing libatk, libgtk, etc.)
- ❌ **GitHub Codespaces** without system dependencies
- ❌ **Docker containers** without X11/GUI support

### Best Practices for Dev Environments:

1. **For Local Development**: Use full automation with Playwright
2. **For Dev Containers**: 
   - Try Firefox (fewer dependencies than Chromium)
   - Use manual screenshots as backup
   - Pre-install system libraries in Dockerfile if possible

3. **For CI/CD**: Use dedicated browser testing environments

### Quick Test:
Run this to check if automation works in your environment:
```bash
npm run test:browser-support
```

This will test both Firefox and Chromium and tell you which browsers work in your dev environment.
